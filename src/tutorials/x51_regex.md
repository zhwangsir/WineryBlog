## 1. 正则是一台状态机

正则表达式（Regex）= 用一个**模式字符串**描述一类文本的形状。编译后是一台小状态机（DFA/NFA）——所以它能出现在任何语言里且行为一致。

元字符速查（背这张表）：

| 元字符 | 含义 | 例 |
| --- | --- | --- |
| `.` | 任意单字符（不含换行） | `a.c` → abc/axc |
| `\d \w \s` | 数字/字母数字下划线/空白 | `\d\d` → 42 |
| `[abc]` | 字符组任选一 | `[aeiou]` → 元音 |
| `[^abc]` | 非此字符组 | `[^0-9]` → 非数字 |
| `^ $` | 行首/行尾 | `^Go` → 以 Go 开头 |
| `* + ?` | 0+ / 1+ / 0或1 次 | `ab+c` → abc/abbc |
| `{2,5}` | 2 到 5 次 | `\d{2,5}` |
| `a|b` | 或 | `cat|dog` |
| `( )` | 分组捕获 | `(\d{4})-(\d{2})` |

## 2. 贪婪与懒惰：新手第一大坑

```javascript
// 贪婪（默认）：吃到最长的
'<div>a</div><div>b</div>'.match(/<div>.*<\/div>/)
// → '<div>a</div><div>b</div>'   ← 整串全吃了！

// 懒惰：加 ? 尽量少吃
'<div>a</div><div>b</div>'.match(/<div>.*?<\/div>/)
// → '<div>a</div>'               ← 第一个就停
```

`*?` `+?` `??` `{m,n}?` 都是懒惰版。**匹配 HTML/XML 用懒惰**（虽然正则解析 HTML 本身是反模式，DOM 解析器才是正道）。

## 3. 分组捕获：提取信息

```javascript
// 基础捕获
const m = '2026-11-20'.match(/(\d{4})-(\d{2})-(\d{2})/);
m[1]; // '2026'   m[2] // '11'   m[3] // '20'

// 命名捕获（可读性神器）
const m2 = 'bob@example.com'.match(
  /(?<user>[\w.]+)@(?<domain>\w+\.\w+)/
);
m2.groups.user;    // 'bob'
m2.groups.domain;  // 'example.com'

// 非捕获分组：只要分组逻辑不要捕获 (?:)
/(?:https?:\/\/)?example\.com/

// 替换中引用捕获组
'2026-11-20'.replace(/(\d{4})-(\d{2})-(\d{2})/, '$3/$2/$1');  // '20/11/2026'
```

## 4. 零宽断言：匹配"位置"而不是字符

```
(?=...)  正向先行：后面必须是 ...
(?!...)  负向先行：后面不能是 ...
(?<=...) 正向后行：前面必须是 ...
(?<!...) 负向后行：前面不能是 ...
```

```javascript
// 密码强度：至少 8 位，含大写、小写、数字
/^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/.test('Passw0rd')   // true

// 千位分隔符：数字插入逗号，但不从"前面必须非空"开始
'1234567'.replace(/\B(?=(\d{3})+(?!\d))/g, ',')            // '1,234,567'

// 抓取价格数字，但跳过"免费"后的 0
/(?<=￥)\d+(\.\d+)?/g                                       // 只取 ￥ 后面的数
```

断言是零宽的——它检查上下文但**不消耗字符**，多个断言可以叠在同一个位置做组合条件。

## 5. 灾难性回溯：正则的 DoS

```javascript
/(a+)+$/.test('aaaaaaaaaaaaaaaaaaaaaaaaaaaaX')
// 指数级回溯！嵌套量词 + 歧义路径 → 每个位置都尝试所有分割
// 单线程被这一行卡死几分钟 —— ReDoS 攻击的经典手法
```

安全守则：
1. 避免嵌套量词 `(a+)+`、`(a|a)*`
2. 用户输入拼进正则前**必须转义**：`str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`
3. 服务端解析用户正则设超时；能用字符串方法（indexOf）就不用正则

## 6. 实用正则配方（存档即用）

```javascript
// 手机号（宽松版）
/^1[3-9]\d{9}$/

// 邮箱（宽松版，严格邮箱正则是传说中 6000 行的正则——别较真）
/^[\w.+-]+@[\w-]+(\.[\w-]+)+$/

// URL
/^https?:\/\/[^\s/$.?#].[^\s]*$/

// 日期 YYYY-MM-DD（含大小月校验就用代码别用正则）
/^\d{4}-\d{2}-\d{2}$/

// 去除多余空白
str.replace(/\s+/g, ' ').trim()

// 驼峰 ↔ 下划线
'helloWorld'.replace(/([A-Z])/g, '_$1').toLowerCase()   // hello_world
'hello_world'.replace(/_([a-z])/g, (_, c) => c.toUpperCase())  // helloWorld
```
