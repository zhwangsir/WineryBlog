## 1. 贪心算法：局部最优 → 全局最优

贪心的关键不是"每次选最大的"而是**能证明局部最优导致全局最优**。

经典贪心题：

- **区间调度**（LC 435 无重叠区间）：按右端点排序，保留最多不重叠区间
- **分发饼干**（LC 455）：小饼干喂小胃口
- **跳跃游戏**（LC 55）：维护最远可达位置

贪心证明方法：**交换论证**——假设存在最优解不是贪心解，通过交换元素构造出贪心解，证明不劣于假设。

## 2. 二分答案：在值域上二分

当答案具有**单调性**（x 可行 → x+1 也可行）时，在答案值域上二分：

```python
def binary_search_answer(lo, hi, check):
    """check(x) 返回 True 表示 x 可行"""
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid          # mid 可行，尝试更小
        else:
            lo = mid + 1      # mid 不可行，尝试更大
    return lo                 # lo = 最小可行值
```

典型应用：

- **LC 410 分割数组最大和**：二分"最大子数组和"的值，check 是否能分 ≤ m 段
- **LC 875 爱吃香蕉的珂珂**：二分吃香蕉速度
- **LC 1011 运输货物**：二分船的运载能力

## 3. 二分查找三大模板对比

```python
# 模板一：找确切值（左右闭区间）
l, r = 0, len(a) - 1
while l <= r:
    m = (l + r) // 2
    if a[m] == t: return m
    if a[m] < t: l = m + 1
    else: r = m - 1

# 模板二：找左边界（第一个 >= t）
l, r = 0, len(a)
while l < r:
    m = (l + r) // 2
    if a[m] < t: l = m + 1
    else: r = m

# 模板三：找右边界（最后一个 <= t）
l, r = -1, len(a) - 1
while l < r:
    m = (l + r + 1) // 2     # +1 防死循环
    if a[m] <= t: l = m
    else: r = m - 1
```
