## 1. 起点：晶体管与逻辑门

现代数字电路的开关单元是 **MOS 晶体管**（视为电压控制的开关）：

- **NMOS**：栅极高电平导通（1 时开关合上）
- **PMOS**：栅极低电平导通（0 时开关合上）

两者互补组合构成 **CMOS**（互补 MOS）——静态功耗近零（只在新状态切换时耗电），是现代芯片的标准工艺。

**反相器（NOT）**：PMOS 接 VDD + NMOS 接 GND，输入 1 → NMOS 通输出接地（0）；输入 0 → PMOS 通输出接 VDD（1）。与非门（NAND）= PMOS 并联在上 + NMOS 串联在下——**NAND 是通用门**（仅用 NAND 可搭出一切逻辑），芯片制造统一工艺的逻辑基础。

## 2. 布尔代数与化简

逻辑电路的行为用布尔代数表达。基本定律：

| 定律 | 表达 |
| --- | --- |
| 德摩根 | ¬(A·B) = ¬A + ¬B；¬(A+B) = ¬A·¬B |
| 分配 | A·(B+C) = A·B + A·C |
| 吸收 | A + A·B = A |
| 异或 | A⊕B = A·¬B + ¬A·B（不同为 1） |

**卡诺图化简**：把真值表排成二维网格，相邻的 1 圈成组（圈越大电路越简）——手工化简到最简两级电路的标准方法。现代工具（逻辑综合器）自动完成，但理解化简原理是读懂硬件描述语言产出的前提。

## 3. 组合逻辑：输出只取决于当前输入

### 加法器
```
半加器：两个 1 位相加 → 和 S = A⊕B，进位 C = A·B
全加器：半加器 + 低位进位 → S = A⊕B⊕Cin；Cout = AB + Cin(A⊕B)
行波进位加法器：N 位 = N 个全加器串联 —— 进位逐级"行波"传播
```

行波进位的延迟随位数线性增长（每级等低位的进位）——**超前进位加法器（CLA）**并行计算所有进位（用 generate/propagate 信号提前推导），是真实 CPU ALU 的做法（用面积换速度）。

### 多路选择器（MUX）与译码器
```
MUX：多个输入选一个输出（sel 决定）—— 数据流的选择器
译码器：n 位输入激活 2^n 输出之一 —— 地址选择（内存寻址的电路基础）
```

**MUX 的通用性**：任何真值表都能用 MUX 搭出来（把函数输入接选择线，把真值表输出值接数据线）——硬件版的查表。

## 4. 时序逻辑：引入记忆

组合逻辑无记忆（同输入同输出）；**时序逻辑引入时钟与状态**——输出取决于当前输入**和历史状态**：

```
D 触发器：时钟上升沿时，把输入 D 锁存到输出 Q（其他时刻 Q 保持）
寄存器：N 个 D 触发器并排 —— 存储 N 位
```

**时钟的作用**：所有触发器在同一时钟沿同步更新——数字电路的"节拍器"。**建立时间/保持时间**约束：输入必须在时钟沿前后保持稳定，违反 = 亚稳态（输出随机，电路的头号敌人）。

## 5. 从触发器到状态机：FSM 的硬件实现

有限状态机（与站内《游戏开发概论》的 FSM 同一思想）的硬件标准结构：

```
        ┌──────────────┐
输入 ──→│ 次态组合逻辑   │──→ D 触发器（当前状态寄存）──→ 输出逻辑 ──→ 输出
   ↑    └──────────────┘         ↑ 状态反馈回次态逻辑        │
   └──────────────────────────────────────────────────────┘
```

计数器 = 最简单的 FSM：状态就是数值，加 1 转移。**交通灯控制器**实例（红黄绿三态 + 定时转移）：

```verilog
// Verilog 硬件描述：三态交通灯
localparam RED = 2'b00, YELLOW = 2'b01, GREEN = 2'b10;
reg [1:0] state;
reg [7:0] timer;

always @(posedge clk) begin
    if (timer == 0) begin
        case (state)
            RED:    begin state <= GREEN;  timer <= 8'd30; end
            GREEN:  begin state <= YELLOW; timer <= 8'd5;  end
            YELLOW: begin state <= RED;    timer <= 8'd30; end
        endcase
    end else timer <= timer - 1;
end
```

这段代码综合成真实电路——`case` 里的每个分支都是组合逻辑的一部分，`state` 寄存器就是 FSM 的记忆单元。

## 6. 从逻辑门到 CPU：一以贯之

把前面的积木组装出 CPU 的核心部件：

| 部件 | 构成 |
| --- | --- |
| 寄存器堆 | 寄存器阵列 + 译码器选择读写口 |
| ALU | 加法器 + 逻辑单元 + 移位器 + MUX 选输出 |
| 内存 | 译码器选址 + 触发器阵列存储 |
| 取指译码 | 计数器（PC）+ 译码器 + 控制逻辑 |

这正是站内《计算机组成：硬件架构》与《汇编语言入门》的电路实现层——**指令的每一步执行都是这些门电路的信号传播**。

## 7. FPGA：可编程的逻辑门海

FPGA（现场可编程门阵列）= 海量的可配置逻辑块（LUT 查找表 + 触发器）+ 可编程互连——**用硬件描述语言（Verilog/VHDL）"写"出电路**：

- 与软件的本质区别：Verilog 描述的是**电路结构**（并行存在），不是顺序执行的指令
- 用途：协议加速、低延迟交易、AI 推理加速卡、原型验证
- 入门：Verilog 写计数器/状态机 → 仿真（testbench）→ 上板（如 Tang Nano 开发板，百元级）

## 8. 陷阱速查表

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 电路偶发输出错乱 | 亚稳态（违反建立/保持时间） | 时序约束分析；两级触发器同步异步信号 |
| 行波加法器高位慢 | 进位逐级传播 | 超前进位/选择进位加法器 |
| 竞争冒险毛刺 | 组合逻辑路径延迟不一致 | 寄存器打拍；避免输出直接反馈输入 |
| 综合后行为与仿真不符 | 代码风格触发不可综合结构 | 只用可综合子集；阻塞/非阻塞赋值规范 |
| 计数器状态跳变异常 | 状态编码未约束 | 显式状态编码 + 默认分支回安全态 |
