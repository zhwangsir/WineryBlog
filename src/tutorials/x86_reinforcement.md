## 1. 强化学习与监督学习的根本区别

| | 监督学习 | 强化学习（RL） |
| --- | --- | --- |
| 反馈 | 每个样本有"标准答案"标签 | 只有**延迟的、稀疏的**奖励信号 |
| 数据 | 静态数据集 | **智能体自己产生**（与环境交互） |
| 目标 | 拟合标签 | 最大化**长期累计奖励** |
| 难点 | 过拟合 | 探索-利用权衡 + 延迟归因 |

** RL 的核心困境**：下棋赢棋在几小时后——中间几百步哪步是"好棋"？这就是**信用分配问题（credit assignment）**；且不尝试就不知道好坏——**探索-利用两难**贯穿始终。

## 2. MDP：强化学习的数学框架

**马尔可夫决策过程** MDP = (S, A, P, R, γ)：

| 元素 | 含义 | 例（走迷宫） |
| --- | --- | --- |
| S 状态集 | 环境的观测 | 每个格子 |
| A 动作集 | 可选操作 | 上/下/左/右 |
| P 转移概率 | s 执行 a 到 s′ 的概率（可能随机） | 走滑冰面可能滑偏 |
| R 奖励函数 | s→s′ 的即时奖励 | 到终点 +1，陷阱 −1，其他 0 |
| γ 折扣因子 | 未来奖励的现值权重（0~1） | 0.9：一步后的奖励值 90% |

**马尔可夫性质**：下一步只取决于当前状态与动作，与历史无关——这让问题可解（否则要记忆全部历史）。γ 的意义：越接近 1 越看重长期回报，越接近 0 越短视。

**回报（Return）**：G = r₁ + γr₂ + γ²r₃ + …——目标：学一个**策略 π(a|s)**（状态到动作的映射），最大化期望回报。

## 3. 价值函数与贝尔曼方程

- **状态价值 V(s)**：从 s 出发按 π 行动的期望回报
- **动作价值 Q(s,a)**：从 s 执行 a 后按 π 行动的期望回报

**贝尔曼方程**——价值函数的递归定义（当前奖励 + 折扣后的未来价值）：

```
V(s) = Σ_a π(a|s) Σ_s' P(s'|s,a) [ R + γ V(s') ]
```

它直接给出**动态规划解法**（值迭代/策略迭代）——但要求已知转移概率 P。**现实世界 P 未知**（不知道滑冰面会滑向哪）→ 需要从经验学习：这就是 Q-Learning。

## 4. Q-Learning：从经验学价值（无模型）

**时差学习（TD）**思想：用"估计的下一状态价值"更新当前估计——**自我 bootstrapping**：

```python
import numpy as np

Q = np.zeros((n_states, n_actions))    # Q 表：状态×动作 → 价值
alpha, gamma, eps = 0.1, 0.95, 0.1

def choose(s):                          # ε-greedy 探索策略
    if np.random.rand() < eps:
        return np.random.randint(n_actions)          # 探索：随机动作
    return int(np.argmax(Q[s]))                      # 利用：当前最优动作

for ep in range(10000):
    s = env.reset()
    done = False
    while not done:
        a = choose(s)
        s2, r, done, _ = env.step(a)
        # Q 更新公式（TD 误差驱动）
        Q[s][a] += alpha * (r + gamma * np.max(Q[s2]) * (1-done) - Q[s][a])
        s = s2
# 收敛后 argmax(Q[s]) 即每个状态的最优动作
```

更新公式的直觉：**新估计 = 旧估计 + α ×（现实 − 旧估计）**——括号里就是 TD 误差（预期与现实的偏差）。

**ε-greedy**：以 ε 概率随机探索、1−ε 概率贪心——**探索-利用的简单平衡**。ε 可随训练衰减（前期多探索、后期多利用）。

## 5. 策略梯度：直接学策略

Q-Learning 只能处理**离散动作**（要 argmax 全动作表）。策略梯度直接参数化策略 π_θ(a|s)（神经网络输出动作分布），按"好的动作提升概率"更新：

```text
∇J(θ) = E[ ∇log π_θ(a|s) × G ]     （REINFORCE）
直觉：回报 G 高的 (s,a) 组合，提高其选择概率
```

- **优点**：支持连续动作（机械臂力矩）、随机策略天然支持
- **缺点**：方差大（G 波动剧烈）→ 基线减除、Actor-Critic（价值网络当基线，如 A2C/PPO）

## 6. 深度强化学习：DQN 三件套

状态空间太大（Atari 像素）表格存不下 → 用神经网络近似 Q：

**DQN 的三个稳定化技巧**（深度 RL 的奠基工作）：
1. **经验回放**：交互样本存缓冲池，随机小批量采样训练——打破样本相关性
2. **目标网络**：用一份冻结的旧网络计算 TD 目标（定期同步）——避免"追自己影子"振荡
3. **奖励裁剪**：统一尺度适配多游戏

后续演进：Double DQN（修过估计）、Dueling（状态价值与优势分离）、PPO（策略梯度 + 裁剪目标，RLHF 的标准算法）。

## 7. 与 LLM 的联系：RLHF

大模型对齐的最后一步就是 RL：

```
1. SFT：指令微调（监督学习阶段）
2. 训练奖励模型：人类对回答的偏好排序 → 学习一个打分模型
3. PPO/RLHF：LLM 生成回答 → 奖励模型打分 → 作为奖励信号更新 LLM
（DPO 是跳过奖励模型直接用偏好对优化的简化版，见站内 LoRA 微调篇）
```

"回答要无害、有帮助"——这些人类模糊偏好无法写成可微损失函数，只能通过 RL 的奖励信号间接注入。

## 8. 陷阱速查表

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 学出来的策略忽好忽坏 | ε 太高/学习率过大 | ε 衰减；调 α |
| Q 值爆炸发散 | 自举放大误差 | 目标网络；奖励归一化裁剪 |
| 收敛到次优策略 | 探索不足 | ε-greedy / 乐观初始化 |
| 奖励设计扭曲行为 | 钻空子（reward hacking） | 奖励对齐真实意图；多信号 |
| 样本效率极低 | 交互昂贵 | 经验回放 / 模型基 RL / 模仿学习起步 |
