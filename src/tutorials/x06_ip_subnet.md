## 1. IPv4 地址结构

32 位二进制 → 4 个字节 → 点分十进制：

```text
192.168.71.121
└─┬─┘└┬─┘└┬─┘└┬─┘
 192   168   71   121
```

**网络部分 + 主机部分**由子网掩码划分。

## 2. 子网掩码与 CIDR

子网掩码标记哪些位是网络号：

```text
IP:      192.168.71.121
掩码:    255.255.255.0    (/24)
────────────────────────
网络号:  192.168.71.0
主机号:  0.0.0.121
```

CIDR 记法：`192.168.71.0/24` 表示前 24 位是网络号，主机位 8 位 → 254 个可用地址（去掉网络地址和广播地址）。

常用 CIDR：

| CIDR | 掩码 | 可用主机 |
|------|------|----------|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /16 | 255.255.0.0 | 65,534 |
| /8 | 255.0.0.0 | 16,777,214 |

## 3. 特殊地址

- `0.0.0.0`：所有网络接口（服务监听用）
- `127.0.0.1`：本地回环
- `255.255.255.255`：广播
- `169.254.x.x`：DHCP 分配失败时的自动私有地址

## 4. 私网地址（RFC 1918）

```text
10.0.0.0/8          (10.0.0.0 ~ 10.255.255.255)
172.16.0.0/12       (172.16.0.0 ~ 172.31.255.255)
192.168.0.0/16      (192.168.0.0 ~ 192.168.255.255)
```

你的内网 `192.168.71.x` 就是 C 类私网——路由器不做 NAT 时无法被公网访问。

## 5. 子网划分实例

把 `192.168.71.0/24` 分成 4 个子网：

```text
借 2 位主机位做子网位 → /26

子网 1: 192.168.71.0/26    (0-63)     可用: 1-62
子网 2: 192.168.71.64/26   (64-127)   可用: 65-126
子网 3: 192.168.71.128/26  (128-191)  可用: 129-190
子网 4: 192.168.71.192/26  (192-255)  可用: 193-254
```

每子网可用主机 = 2^6 - 2 = 62（去掉网络地址和广播地址）。

## 6. 实用命令

```bash
# Windows
ipconfig /all
route print

# Linux
ip addr show
ip route show
```
