## 1. 概率的三种解读

| 解读 | 含义 | 例 |
| --- | --- | --- |
| 频率派 | 长期重复试验中事件发生的比例 | 抛硬币 50% |
| 贝叶斯派 | 对命题的**信念程度**（可随证据更新） | "明天下雨概率 70%" |
| 公理化 | 满足柯尔莫哥洛夫公理的测度 | 数学严谨性 |

三种解读共享同一套数学运算，分歧在"概率是什么"的哲学与推断方法（频率派假设检验 vs 贝叶斯后验更新）。现代 ML 两者都用：损失函数多为频率派（极大似然），先验与正则化常是贝叶斯思想。

## 2. 条件概率与贝叶斯定理

**条件概率**：P(A|B) = P(A∩B) / P(B)——"在 B 发生的前提下 A 的概率"。

**贝叶斯定理**——由条件概率定义直接变形：

```
P(A|B) = P(B|A) × P(A) / P(B)
           后验 = 似然 × 先验 / 证据
```

**经典应用——疾病检测悖论**：某病发病率 1/1000，检测试剂准确率 99%（有病检出 99%、无病误报 1%）。某人检测阳性，**真有病的概率是多少？**

```
P(病|阳) = P(阳|病)×P(病) / P(阳)
         = 0.99 × 0.001 / (0.99×0.001 + 0.01×0.999)
         ≈ 0.09        ← 只有 9%！
```

直觉冲击的根源：**基础比率（先验）太低**——健康人基数大，1% 误报的绝对人数远超真阳性。**这就是"为什么检测阳性要复检"的数学答案**（复检 = 用新证据二次更新后验）。

贝叶斯是垃圾邮件过滤（词 → 是否垃圾的后验）、朴素贝叶斯分类器、贝叶斯优化的共同地基。

## 3. 随机变量、期望与方差

- **期望 E[X]**：加权平均值（长期的"中心位置"）
- **方差 Var(X) = E[X²] − (E[X])²**：偏离期望的程度；标准差 = √方差

**期望的线性性**（无论独立与否都成立）：E[aX+bY] = aE[X]+bE[Y]——这是"期望估算"的万能工具：

```text
例：抽奖箱 10 券 1 大奖。随机抽 3 张，期望中大奖数？
对称性：每张券被抽中的概率 = 3/10
E[大奖数] = 10 × (3/10) × (1/10 大奖率) = 0.3
```

**应用**：算法期望复杂度（快排随机 pivot 的 O(n log n) 期望）、负载均衡（哈希桶期望负载）、随机化算法正确性分析（站内《哈希与字符串算法》的期望哈希）。

## 4. 常见分布速查

| 分布 | 场景 | 期望/方差 | 无记忆性 |
| --- | --- | --- | --- |
| 伯努利 | 单次成败 | p / p(1−p) | — |
| 二项 | n 次独立成败计数 | np / np(1−p) | — |
| 泊松 | 单位时间稀有事件数（λ） | λ / λ | — |
| 几何 | 首次成功前失败次数 | (1−p)/p | ✓ 每次重新开始 |
| 正态 | 大量独立因素叠加 | μ / σ² | — |

**中心极限定理（CLT）**：大量独立同分布随机变量之和趋向正态（与原分布无关）——正态无处不在的原因（误差 = 无数小扰动之和）。也是假设检验能用正态近似的根据。

## 5. 假设检验：p 值的真正含义

```text
H0 零假设：A/B 两组无差异
H1 备择：有差异
p 值 = 假设 H0 为真时，观察到"当前或更极端数据"的概率
```

**p < 0.05 的正确读法**：在无差异的世界里，出现这种数据的可能性小于 5%——**它不是"H1 为真的概率是 95%"**（那是贝叶斯的说法，频率派不这么算）。

两类错误：

| | H0 实际为真 | H0 实际为假 |
| --- | --- | --- |
| 拒绝 H0 | **第一类错误 α**（误报） | 正确（检出功效 1−β） |
| 不拒绝 H0 | 正确 | **第二类错误 β**（漏报） |

**A/B 测试要点**：样本量不足 → 检测功效低（真改进测不出）；**多重比较**（测 20 个指标总有一个 p<0.05——假阳性）→ 校正（Bonferroni）；**提前停止**（看几天有显著就停）→ p 值失真。这些是数据团队最常犯的统计错误。

**贝叶斯 A/B 的替代视角**：直接计算 P(B 优于 A | 数据) 后验分布——对"我想知道 B 好多少"的业务问题更直观（代价是要选先验、计算更重）。

## 6. 信息论：熵——不确定性的度量

**香农熵**：H(X) = −Σ p(x) log₂ p(x)（单位：比特）

```
均匀硬币: −(0.5 log₂0.5 + 0.5 log₂0.5) = 1 比特     （每次抛出 1 bit 信息）
偏硬币 99%正: −(0.99×log₂0.99 + 0.01×log₂0.01) ≈ 0.08 比特 （几乎无不确定性）
```

直觉：**熵 = 最好压缩方案下的平均编码长度下界**——等概率的分布最难压缩（信息量大），偏斜分布可短码（信息量小）。这就是哈夫曼编码能达到的理论极限的来源。

**交叉熵与 KL 散度**：

```
交叉熵 H(p,q) = −Σ p(x) log q(x)      用编码 q 编码真实分布 p 的平均长度
KL 散度 = H(p,q) − H(p)               q 偏离 p 的"额外代价"（≥0）
```

**与 ML 的联系**：分类的交叉熵损失 = 模型分布 q 对真实分布 p 的交叉熵——最小化损失 = 让模型逼近真实分布。语言模型的困惑度 = 2^交叉熵（下个 token 的平均候选数）。

**互信息 I(X;Y) = H(X)+H(Y)−H(X,Y)**：知道 Y 后 X 的不确定性减少量——特征选择（哪些特征与标签互信息大）、信息瓶颈理论的基石。

## 7. 陷阱速查表

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 检测阳性就确诊 | 忽略基础比率 | 贝叶斯更新先验 |
| p<0.05 就宣称"95% 置信有效" | p 值误解 | 正确读法：H0 下数据的极端性 |
| 测 20 个指标挑显著的 | 多重比较假阳性 | Bonferroni 校正 / 预注册主指标 |
| A/B 看到趋势就提前停止 | 序贯检验失真 | 固定样本量或序贯方法 |
| 用平均值评估重尾数据 | 长尾由少数极端值主导 | 看中位数/分位数 |
| 幸存者偏差 | 只统计了"活下来"的样本 | 明确抽样框架与遗漏群体 |
