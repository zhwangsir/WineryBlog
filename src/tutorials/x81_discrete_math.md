## 1. 为什么 CS 的数学是"离散"的

计算机处理的是**可数的、分立的**对象：比特、整数、字符、图节点、程序状态。与连续数学（微积分，研究"平滑变化"）相对，**离散数学研究"可数的结构与关系"**——它是算法、数据库（关系代数）、密码学（数论）、编译器（逻辑与自动机）、AI（图与概率）的共同地基。

一句话：**连续数学描述物理世界，离散数学描述计算世界**。

## 2. 集合与关系

集合运算：并 ∪、交 ∩、差 −、补 ′、笛卡尔积 A×B。恒等式（德摩根等）支撑逻辑化简。

**关系（relation）**是 A×B 的子集——描述元素间的关联。关系的四种性质：

| 性质 | 定义 | 例 |
| --- | --- | --- |
| 自反 | (a,a) 都在 | ≤ |
| 对称 | aRb ⇒ bRa | = |
| 反对称 | aRb 且 bRa ⇒ a=b | ≤ |
| 传递 | aRb 且 bRc ⇒ aRc | ≤、<（<不自反） |

**等价关系**（自反+对称+传递）→ 划分**等价类**——"模 n 同余"就是等价关系，把整数划分成 n 个类（哈希桶的数学原型）。**偏序**（自反+反对称+传递）→ 拓扑排序的依赖关系（编译/任务调度）。

## 3. 命题逻辑与谓词逻辑

命题：可判真假的陈述。联结词：¬、∧、∨、→（蕴含）、↔。

**实质蕴涵的坑**：`P → Q` 仅在 P 真 Q 假时为假——P 为假时整个蕴含**恒真**（"vacuously true"）：

```
"如果 2+2=5，那么我就是皇帝" —— 逻辑上为真（前提为假的蕴含恒真）
```

数学证明中大量使用这种"空洞真"——比如证明全称命题时，对不满足前提的元素直接跳过。

**谓词逻辑**引入量词：∀（全称）、∃（存在）。量词的否定：`¬∀x P(x) ≡ ∃x ¬P(x)`——"不是所有人都对" = "至少有一个人错"。**德摩根在量词上的展开**是 SQL NOT IN 语义、测试边界设计的理论基础。

## 4. 数论：模运算与 RSA 的地基

**模运算**：a ≡ b (mod n) 意为 a、b 除以 n 余数相同。性质：

```
(a + b) mod n = ((a mod n) + (b mod n)) mod n
(a × b) mod n = ((a mod n) × (b mod n)) mod n
```

**欧几里得算法**求 GCD（辗转相除）：

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
# gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6
```

正确性依据：gcd(a,b) = gcd(b, a mod b)——更小的问题同解。

**费马小定理**：p 为素数且 gcd(a,p)=1 → a^(p−1) ≡ 1 (mod p)。它是 RSA 的数学支柱：取两个大素数 p、q，n=pq，选 e 使 ed ≡ 1 (mod (p−1)(q−1))——加密 m^e mod n、解密 c^d mod n，由欧拉定理还原。**素数分布的稀疏性**保证大素数难找（安全），**大数分解难**保证 n 难破解（机密）。

**应用延伸**：哈希取模（站内 HashMap）、循环缓冲区、分布式一致性哈希——mod 无处不在。

## 5. 图论基础

图 G=(V, E)：顶点集+边集。有向/无向、带权/无权。基本概念：

- **度**：顶点关联的边数（有向图分入度/出度）——握手定理：所有顶点度数之和 = 2×边数
- **路径/环**：连通性判断（BFS/DFS）
- **有向无环图 DAG**：依赖关系图（拓扑排序、编译依赖、任务调度）

**图论的应用密度极高**：社交网络（图）、网页排序（PageRank 是特征向量）、任务依赖（DAG 拓扑排序）、最短路（Dijkstra）——算法细节见站内《图与遍历算法（BFS/DFS/拓扑）》。

## 6. 组合计数：排列组合与鸽巢

- **排列**：从 n 个取 k 个**有序**：P(n,k) = n!/(n−k)!
- **组合**：无序：C(n,k) = n!/(k!(n−k)!)
- **鸽巢原理**：n+1 只鸽子进 n 个巢，必有一个巢 ≥2 只——"生日悖论"（23 人中两人同生日的概率 >50%）就是鸽巢+概率的组合

计数在算法中的应用：证明哈希冲突必然存在（无限 key 有限桶）、循环移位计数、状态空间大小估算。

## 7. 数学归纳法：算法正确性的证明工具

归纳法两步：**基础情形**（n=0/1 成立）+ **归纳步骤**（假设 n=k 成立 → 证明 n=k+1 成立）。

```text
命题：循环不变式——每轮迭代开始时，sum = 1+2+...+i
基础：i=1 时 sum=1 ✓
归纳：假设第 i 轮成立；第 i+1 轮 sum += (i+1) → sum = 1+...+i+(i+1) ✓
结论：对所有 n，循环结束时 sum = n(n+1)/2 ✓
```

**循环不变式**就是归纳法在算法证明里的化身——是证明贪心/迭代算法正确性的标准方法（站内《贪心与二分答案专题》的正确性论证即此法）。

## 8. 陷阱速查表

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 证明里前提为假仍推出结论 | 实质蕴涵的空洞真 | 识别 vacuous true，聚焦满足前提的情形 |
| 模运算结果为负（语言差异） | 部分语言 % 对负数返回负 | `((a % n) + n) % n` 归一化 |
| 哈希假设不冲突 | 鸽巢原理违背 | 冲突处理是必须的（链表/开放寻址） |
| 忽略空集/边界情形 | 全称命题的 vacuous case | 测试用例覆盖空输入 |
| 递归没有基础情形 | 归纳法第一步缺失 | 先写 base case 再写递归 |
