## What's new

1.   Oct 21, 2026 GuideHow image layers and the build cache work

Find out why changing one line of code can make docker build reinstall every dependency. See the layers your Dockerfile creates, then reorder it so the build cache skips the slow steps. 20 min
2.   Oct 21, 2026 GuideKeep data with volumes and bind mounts

A container's files disappear when you remove it. Keep a to-do app's database in a named volume so it survives a new container, bind-mount a directory so you can see the database on your own disk, and learn which one to reach for. 20 min
3.   Oct 21, 2026 GuideRun a multi-container app with Compose

Connect a to-do app to a MySQL database by hand on a Docker network, feel how many flags that takes, then describe the same app in one compose.yaml and run it with a single command. 25 min
4.   Oct 21, 2026 GuideRun your first container

Run a real to-do app in a container, reach it from your browser, run a second copy beside it, configure it with an environment variable, look inside it, and see what happens to its data when you remove it. 20 min
5.   Oct 21, 2026 GuideShare your image on Docker Hub

Name your image for a registry, sign in, and push it to Docker Hub with a version tag and latest, then pull it back and run it the way anyone else would. 15 min
6.   Oct 21, 2026 GuideShrink your image with multi-stage builds

Split a Node.js Dockerfile into build stages and a slim final stage, so the image ships the built frontend and production dependencies but leaves the compilers and dev tools behind. Then measure the difference. 20 min
