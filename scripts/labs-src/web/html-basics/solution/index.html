看懂酒标

酒标上最有用的信息是产区、年份和葡萄品种。产区告诉你这瓶酒出生在哪里，年份告诉你那一年的天气如何，品种则决定了它大致的口感。

先认识三个最常见的红葡萄品种：

  • 赤霞珠：单宁重，有黑加仑和青椒的气息。
  • 黑皮诺：酒体轻，酸度明亮，常带樱桃香气。
  • 梅洛：口感柔和，李子和巧克力的味道。

正式开喝之前，按顺序做三件事：

  1. 看颜色：倾斜酒杯，观察边缘的色调。
  2. 闻香气：先轻闻再摇杯，分辨果香和橡木桶的香气。
  3. 尝味道：小口啜饮，留意酸度、单宁和余味。
